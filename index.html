THE REFINERY METHODOLOGY

Three Steps to Job-Ready

Work on a real, broken artifact. Fix it under senior review. Graduate with verifiable proof.

01. $ step-01 simulate

Simulate Industry Environments

Work inside real-world codebases that are messy, undocumented, and packed with the actual types of bugs encountered on the job, steering clear of simple toy examples.

> No greenfield tutorials. Real repos only.
02. $ step-02 debug

Debug Under Pressure

Engage in timed debugging challenges, code reviews, and production incident simulations designed to build practical muscle memory that cannot be forgotten.

> Master race conditions, stack traces & leaks.
03. $ step-03 ship

Ship Real Projects

Complete end-to-end tasks featuring Pull Request (PR) reviews, CI/CD pipelines, and stakeholder feedback so graduates leave with a portfolio proving they can deliver.

> Verified deliverables ready for hiring managers.
STRUCTURED TIMELINE

The 9-Week Industry-Simulation Curriculum

Designed specifically to transform theory into muscle memory across four intensive phases.

WEEKS 1–2

Step 01: Skills Brushup

  • ▸ Core stack refresh & starter app triage
  • ▸ Git workflows (branching, commits, PRs)
  • ▸ Reading stack traces & server logs
  • ▸ Authentication fundamentals & token flows
WEEKS 3–4

Step 02: Production Debugging

  • ▸ Interpreting complex, nested stack traces
  • ▸ Debugging race conditions & async bugs
  • ▸ Memory leak profiling & heap analysis
  • ▸ Reproducing intermittent flaking failures
WEEKS 5–7

Step 03: Codebase Navigation

  • ▸ Rapid onboarding to massive repositories
  • ▸ Handling legacy, zero-documentation code
  • ▸ Tracing data across distributed services
  • ▸ Making safe modifications without regression
WEEKS 8–9

Step 04: Shipping Features

  • ▸ End-to-end feature delivery under PR review
  • ▸ Writing unit & integration tests for legacy code
  • ▸ CI/CD pipelines & automated build validation
  • ▸ Live Capstone presentation & incident post-mortem
